# Cloudify Tec

Sitio web institucional de Cloudify Tec, empresa de tecnología especializada en soluciones de nube, automatización e inteligencia artificial para PyMEs de Argentina y América Latina.

---

## Demo

[Ver sitio publicado](https://cloudify-tec.vercel.app)

---

## Descripción del proyecto

Cloudify Tec nació en Jujuy, Argentina, con el objetivo de ayudar a pequeñas y medianas empresas a trabajar mejor usando tecnología moderna. La idea principal no es reemplazar personas, sino hacer que puedan hacer su trabajo de forma más rápida y eficiente.

Este sitio institucional fue desarrollado como proyecto final del curso Desarrollo Web Flex en CoderHouse, aplicando HTML semántico, SASS modular, responsive design y buenas prácticas de SEO.

---

## Páginas

- **Inicio** — Presentación general de la empresa y sus servicios principales
- **Nosotros** — Misión, visión, valores y objetivos estratégicos
- **Servicios** — Catálogo completo de soluciones tecnológicas
- **Reseñas** — Testimonios de clientes
- **Contacto** — Formulario de contacto e información de la empresa

## Tecnologías

- HTML5 con etiquetas semánticas y meta tags SEO

- Boxicons para iconografía
- Google Fonts — tipografía Inter
- Git y GitHub para control de versiones
- Vercel para el deploy

## Cómo correr el proyecto localmente

Cloná el repositorio:

```bash
git clone https://github.com/RD0503/Cloudify-Tec.git
```

Abrí el proyecto en VS Code, instalá la extensión Live Sass Compiler de Ritwick Dey, activá Watch Sass desde la barra inferior y abrí el index.html con Live Server.
